# Phase 01 Dataset Inventory

## Real PCB image pair

The existing project pair is `datasets/samples/reference.jpg` (4605 × 3454) and
`datasets/samples/test.jpg` (2390 × 1792). Both files were readable during
inspection. Byte-for-byte copies are stored at
`datasets/real_pcb/reference.jpg` and `datasets/real_pcb/test.jpg`; the original
sample files remain unchanged. The images depict a PCB, but their source,
capture conditions, and defect labels are not documented. No defect status is
asserted.

## Synthetic demo pair

The existing demo-style pair is
`datasets/samples/exampleLocal/reference.jpg` and
`datasets/samples/exampleLocal/test.jpg`, both 640 × 480. The generator in
`backend/create_demo_images.py` previously wrote to this folder. Its source
constructs a schematic PCB-like image with a scratch-like line and a small
circular mark added to the test image. The existing files visually match that
design, but their creation history cannot be independently verified.

The generator now writes new images to `datasets/synthetic/reference.jpg` and
`datasets/synthetic/test.jpg` and refuses to overwrite either target. This
generated pair is 640 × 480. It is synthetic test data, not a real PCB or
defect-validation dataset.

## Output directories

`outputs/baseline/` and `outputs/improved/` are reserved for future result
sets. Existing experiment outputs under `outputs/`, including the
`sensitive/`, `conservative/`, and `synthetic/` results, were left in place.

## Provenance notes

The real-image designation is based on the existing project use and the
visible PCB photograph, not verified source records. The synthetic images are
generated by local project code. There is no verified manufacturing source,
capture metadata, or ground truth for the real-image pair.
